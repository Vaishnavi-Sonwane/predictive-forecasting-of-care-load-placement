# Unified Mentor Project Submission Checklist

The submission page requires five HTTPS URLs. No URLs have been entered or submitted.

| Required field | Current state | Needed to complete |
|---|---|---|
| GitHub Repository Link | Not published | Create or choose a repository and publish the project files. |
| Research Paper Link | Paper is ready locally | Publish the paper in the repository or another public HTTPS location. |
| Deployed Project Link | Dashboard is ready locally | Deploy the Streamlit app to a public HTTPS host. |
| Project Explanation Video Link | Not recorded | Record a walkthrough, then provide its HTTPS link. A draft script is in `video_scripts.md`. |
| Internship Experience & Feedback Video Link | Not recorded | Record truthful first-person feedback about your own experience, then provide its HTTPS link. Use the prompts in `video_scripts.md`. |

## Before entering the URLs

1. Confirm the repository and deployment should be public. The dataset is public, but publishing makes the code and project outputs accessible to anyone with the link.
2. Deploy the dashboard and open its public URL to confirm it loads.
3. Publish the research paper and confirm its public URL opens without signing in.
4. Record and upload both videos to a service that provides public HTTPS links.
5. Review all five URLs in the form, then submit the form yourself or explicitly authorize submission after review.
